## 一、课程地图与复习方法
### 1.1 一条主线串起五章
任务要求 → 选择结构与末端工具 → 建立坐标系 → 正运动学确认位置 → 逆运动学求关节量 → 雅可比分析速度与奇异性 → 轨迹规划安排时间 → 控制器跟踪 → 传感器反馈。
机械结构回答“能做什么”；运动学回答“在哪里、怎么动”；动力学回答“需要多大力”；轨迹规划回答“什么时候到达”；控制回答“如何让实际运动跟上目标”。
### 1.2 建议学习优先级
|层级|必须掌握|自测要求|
|基础识记|六个子系统、结构形式、技术参数|不看资料解释术语并举例|
|核心计算|齐次变换、D-H、平面 2R 正逆解|能独立列矩阵并检查量纲|
|重点综合|雅可比、奇异位形、三次轨迹|会求导、代入、检查边界条件|
|提升应用|动力学、闭环控制、标定、避障|能说明模型假设与工程限制|

复习建议：第 1 天完成基础与结构；第 2 天练位姿；第 3 天练 D-H 与正逆解；第 4 天练雅可比；第 5 天练轨迹；第 6 天补动力学与控制；第 7 天闭卷做题并整理错因。此顺序是学习建议，不是考试范围预测。
### 1.3 全文统一符号
q：关节变量列向量；转动关节单位通常为 rad，移动关节为 m。q̇、q̈：速度和加速度。p：位置；R：3×3 旋转矩阵；T：4×4 齐次变换；J：雅可比；τ：关节广义驱动力；F：末端力/力矩。
采用右手坐标系、列向量、主动旋转。⁽ᴬ⁾T_B 表示 B 坐标系在 A 系中的位姿，可把 B 系坐标变成 A 系坐标。V=[v;ω] 表示先线速度、后角速度；F=[f;m] 与之配对。部分教材采用相反排序，使用时必须整体转换。

## 二、第 1 章：机器人基础知识
【课件主线】对应第 1 章第 4—66 页；练习见原课件第 67—68 页。
### 2.1 定义、特点与发展
工业机器人可概括为用于工业自动化、能自动控制、可重复编程、可完成多用途操作的机械系统。重点不是“长得像人”，而是执行机构、可编程能力以及与任务相关的自动化功能。
课件强调可编程性、通用性、适应性及拟人化特征。其中拟人化不是所有机器人的必要条件；固定程序工业机器人也不一定具有高级自主推理能力。
发展线索可记为：示教再现 → 感知反馈 → 感知、决策与动作结合。三类能力并存，不应理解成后一类已经完全替代前一类。工业机器人历史与服务机器人发展用于理解背景，不必把未经核实的“第一台”细节作为计算课的重点。
机器人学涉及机械、控制、传感器、计算机、电学、人工智能等多学科。典型应用：搬运、码垛、焊接、喷涂、装配、医疗辅助、巡检、灾害救援。
### 2.2 常见分类与选型
|类型|典型定位关节|特点|适用任务|
|直角坐标型|PPP|运动直观、结构刚性较易保证；裸三轴不调姿态|龙门搬运、直线定位|
|圆柱坐标型|RPP|回转与径向/轴向移动组合|上下料、回转搬运|
|球坐标型|RRP|回转、俯仰、伸缩组合|具有球壳状可达区域的操作|
|关节型|常见 RRR 定位加腕部|灵活、绕障能力较好；运动学与控制复杂|焊接、喷涂、多姿态装配|
|SCARA【拓展】|典型 RRPR|水平转动配合竖直移动及工具转动|平面装配、快速取放|
|Delta【拓展】|典型并联机构|运动部件轻、适合高速轻载；工作空间受限|分拣、包装|

R 表示转动副，P 表示移动副。表中是典型结构，不代表所有产品。按用途还可分工业、服务、特种；按控制能力可分示教再现、感知、智能等。不同分类维度可以交叉，不能把“智能”当成与“工业”完全互斥的类别。
### 2.3 组成：六个子系统
1. 驱动系统：电机、液压或气动执行元件，提供能量与运动。
2. 机械结构系统：机身、臂、腕、末端执行器及传动部件。
3. 感知系统：获取内部状态和外部环境，如编码器、相机、力传感器。
4. 机器人—环境交互系统：与夹具、输送线、其他设备交换信号并协调动作。
5. 控制系统：生成控制指令，处理程序与反馈，完成运动控制。
6. 人机交互系统：示教器、操作面板、显示报警等。
可用“感知—决策/控制—执行”理解基本功能，用六子系统回答系统组成题。传感器属于内部还是外部，应看其测量对象与用途，不能只靠名称判断。
### 2.4 技术参数：定义与工程意义
|参数|含义|最容易混淆的点|
|自由度|确定机构构形所需的独立变量数|不等于电机数；约束、耦合会改变关系|
|工作空间|选定末端参考点或位姿的可达集合|必须说明参考点、姿态要求与关节限制|
|灵巧工作空间|可在规定姿态集合下完成任务的位置集合|若定义为任意姿态可达，通常是可达空间的子集|
|额定负载|厂商规定条件下允许的末端载荷|计入工具、工件；还查重心、惯量和速度限制|
|定位准确度|实际到达位置与目标位置的一致程度|偏差小，不等于重复散布一定小|
|重复定位精度|重复执行同一指令时结果的集中程度|每次都偏同一方向，也可能重复性很好|
|速度、加速度|运动效率与动态能力指标|受负载、行程、振动与制动条件约束|

例：目标位置 100 mm，连续测量为 101.00、101.01、100.99 mm。结果集中但均值偏离目标约 1 mm，说明重复性好而绝对定位存在偏差。精确评价还需规定测试条件和统计方法。
选型顺序：工艺与姿态 → 工作空间 → 负载/重心/惯量 → 精度与节拍 → 环境与安全 → 接口与维护成本。最大速度不是越高越好，短行程中加减速能力往往比标称速度更影响节拍。

## 三、第 2 章：机器人的机械结构
【课件主线】对应第 2 章第 4—78 页。
### 3.1 机身、臂、腕、手的分工
|部件|核心功能|结构与设计关注点|
|机身/基座|支承并传递载荷，提供总体安装基础|回转升降、回转俯仰、直移；基础刚度|
|臂部|改变腕部和工具在空间的位置|伸缩、屈伸、回转；工作范围与惯量|
|腕部|主要调整末端工具姿态|臂转、俯仰/偏转、手转；紧凑与传动耦合|
|手部/末端执行器|直接抓取或执行工艺|夹爪、吸盘、焊枪、喷枪；互换与检测|

机身与臂部配置：横梁式、立柱式、机座式、屈伸式。一般以臂定位、腕调姿来理解，但完整机构的运动往往相互耦合，不能说臂部绝对不影响姿态。
刚度是抵抗弹性变形的能力；强度是抵抗失效破坏的能力；平稳性关注运动冲击、振动及速度变化。相同材料、质量和受力条件下，合理空心截面可提高材料利用效率，但不能脱离截面方向及约束条件断言某截面永远更好。
### 3.2 手腕与柔顺装配
常见腕部由若干转动关节组合，三条独立转轴可实现较丰富的姿态调整。轴孔装配中，微小位置或角度误差容易导致卡滞。
被动柔顺：借助弹性结构或远心柔顺机构，利用接触力自动微调；结构简单，但适应范围有限。
主动柔顺：根据力/视觉反馈调整运动或控制目标；适应性强，但需要传感器、算法与稳定性设计。
### 3.3 末端执行器与抓取可靠性
|类型|原理/用途|主要限制|
|摩擦夹持|法向夹紧力产生摩擦；常见两指、三指|摩擦系数、接触压力、滑移与变形|
|钩托式|几何支承载荷|需要可钩托结构与合适进入方向|
|弹簧式|弹性力保持小工件|夹持力和适用尺寸范围有限|
|真空吸附|内外压差产生吸力|密封、泄漏、表面粗糙度和吸盘有效面积|
|磁吸附|磁力作用于铁磁性工件|材料、剩磁、断电保持与释放方式|
|灵巧多指手|多接触、多自由度协同|控制、感知、可靠性及成本复杂|

【拓展公式】两指对称摩擦夹持，若每指法向力为 N，静态竖直提举所需条件为 2μN ≥ Kmg。向上加速 a 时可保守写成 2μN ≥ Km(g+a)。K 为安全系数，此式忽略偏心力矩、接触不均匀与复杂姿态。
【拓展公式】理想真空吸附力 F=Δp·A。选型时用有效面积并考虑泄漏、加速度、安全系数；侧向载荷还依赖摩擦，不能直接套法向吸力。
### 3.4 驱动方式与电机
|驱动|优点|局限|典型应用|
|电动|控制接口方便，易闭环调速定位|需匹配减速器、驱动器、散热与制动|工业机器人关节|
|液压|功率密度和输出力较大|泄漏、维护、液压源及非线性|高载荷执行机构|
|气动|结构相对简单、动作快|空气可压缩，精密位置控制更困难|夹爪、吸盘、简单执行动作|

步进电机按脉冲产生步进运动，常用开环控制，负载过大或速度过高可能失步。伺服系统利用传感器反馈，控制位置、速度或力矩，但仍会受到饱和、跟随误差和故障限制。
### 3.5 传动机构与传动路线
直线传动：齿轮齿条、滚珠丝杠、同步带滑台、液压缸。转动传动：齿轮轮系、同步带、谐波减速器、RV 减速器。
分析传动路线时按“驱动源 → 输入构件 → 中间传动 → 输出关节 → 末端动作”逐级说明，并检查转向、传动比、效率、间隙和刚度。
谐波减速器核心：波发生器、柔轮、刚轮。典型优点是紧凑、大减速比；需考虑柔轮疲劳、扭转柔性及额定载荷。RV 常用于较高载荷与刚度要求的关节，但最终由具体产品性能决定。
【拓展公式】定义减速比 i=ω_in/ω_out，则 ω_out=ω_in/i，理想化考虑效率 η 后 τ_out≈ηiτ_in（取幅值）。高减速比不等于无限承载，仍受齿轮强度、热和冲击限制。
【辨析】刚轮固定、波发生器输入、柔轮输出时：ω_f/ω_h=−(Z_c−Z_f)/Z_f。若 Z_c=100、Z_f=98，则 i=−49，表示柔轮反向、速度为输入的 1/49。课件第 75 页“50 圈换 1 圈”与这组齿数及此连接条件不一致；若柔轮 100 齿、刚轮 102 齿，才对应减速比幅值 50。

## 四、第 3 章：位姿与正逆运动学
【课件主线】位姿第 5—24 页；变换第 25—49 页；D-H 与正解第 50—74 页；逆解第 75—88 页。
### 4.1 位置、方向与姿态
位置用三维向量 p=[x,y,z]ᵀ 表示；方向向量表示朝向，单位方向向量的模为 1。刚体姿态用旋转矩阵 R 表示，其三列是动系三个单位坐标轴在参考系中的表达。
RᵀR=I，det(R)=+1，R⁻¹=Rᵀ。
三个方向余弦不是任意独立数，必须满足正交、单位长度与右手规则。空间刚体一般有 3 个位置自由度和 3 个姿态自由度，而不是旋转矩阵的 9 个元素都独立。
齐次点：[x,y,z,1]ᵀ；齐次方向：[vx,vy,vz,0]ᵀ。更一般地，[a,b,c,w]ᵀ 且 w≠0 对应点 (a/w,b/w,c/w)。方向向量的前三项不一定单位化，只有单位方向才要求模为 1。
### 4.2 基本旋转矩阵
记 c=cosθ，s=sinθ；正角由右手定则确定。
```text
Rx(θ) = [1  0  0;  0  c −s;  0  s  c]
Ry(θ) = [c  0  s;  0  1  0; −s  0  c]
Rz(θ) = [c −s  0;  s  c  0;  0  0  1]
```
行内分号表示换行。检查方法：θ=0 得单位阵；RᵀR=I；绕 z 轴 +90° 应把 x 正向转到 y 正向。
### 4.3 齐次变换、复合与求逆
```text
T = [ R  p ]      T⁻¹ = [ Rᵀ  −Rᵀp ]
    [ 0  1 ]            [  0      1  ]
p_A = R_AB p_B + p_AB
⁽ᴬ⁾T_C = ⁽ᴬ⁾T_B · ⁽ᴮ⁾T_C
```
平移只作用于点，不改变自由方向向量。T 的逆不是普通转置，逆变换的平移也通常不等于直接取 −p。
相对于固定参考系施加运动：T_new=ΔT·T_old。相对于当前自身坐标系施加运动：T_new=T_old·ΔT。连续固定轴操作时，后发生的算子写在更左侧。该规则建立在本文列向量与主动运动约定下。
矩阵乘法通常不交换：先转后移与先移后转一般结果不同。解题必须写明旋转轴属于哪个坐标系。
### 4.4 典型例题：固定轴旋转
原课件第 3 章第 40、89 页：U=(8,1,4)，先绕固定 X 轴 +90°，再绕固定 Z 轴 +90°。
第一步：Rx(90°)U=(8,−4,1)。第二步：Rz(90°)(8,−4,1)=(4,8,1)。故齐次结果 W=[4,8,1,1]ᵀ。
常见错误：把运算写成 RxRzU；把 90 直接传入要求弧度的 sin；漏写方向与坐标系约定。
### 4.5 标准 D-H 参数法
本文采用标准 D-H：关节 i 的轴为 z_(i−1)，x_i 沿相邻 z 轴的公垂线方向。参数表与坐标系必须配套。
|参数|标准 D-H 含义|变量属性|
|θ_i|绕 z_(i−1) 从 x_(i−1) 转到 x_i 的角|R 关节的变量|
|d_i|沿 z_(i−1) 的偏距|P 关节的变量|
|a_i|沿 x_i 的连杆长度|刚性连杆通常为常量|
|α_i|绕 x_i 从 z_(i−1) 转到 z_i 的扭角|刚性连杆通常为常量|

A_i=Rz(θ_i)·Tz(d_i)·Tx(a_i)·Rx(α_i)。令 cθ=cosθ_i、sθ=sinθ_i、cα=cosα_i、sα=sinα_i：
```text
A_i = [ cθ  −sθcα   sθsα   a_i cθ
        sθ   cθcα  −cθsα   a_i sθ
         0     sα      cα       d_i
         0      0       0         1 ]
⁽⁰⁾T_n = A_1 A_2 … A_n
```
建模步骤：画关节轴 → 定 z 轴 → 定公垂线与 x 轴 → 按右手规定 y 轴 → 列参数表 → 写各 A_i → 连乘 → 验证零位与一个已知构形。
平行、相交或重合轴存在不同的合法建系选择，因此不同参数表未必互相矛盾。标准 D-H 与改进 D-H 的建系和乘法顺序不同，不能只换参数下标而套同一个矩阵。
若任务定义在工具中心点 TCP，须继续乘工具变换：T_0,TCP=T_0,n·T_n,TCP。更换工具后不能忽略这一步。
### 4.6 平面 2R 机械臂：必须会的模型
设连杆长 l₁、l₂，两个关节轴平行 z，q₂ 为第二杆相对第一杆的转角，末端点在第二杆端。
```text
x = l₁ cosq₁ + l₂ cos(q₁+q₂)
y = l₁ sinq₁ + l₂ sin(q₁+q₂)
φ = q₁+q₂
```
取标准 D-H：两行分别为 (θ=q₁,d=0,a=l₁,α=0)、(θ=q₂,d=0,a=l₂,α=0)。末端旋转为 Rz(q₁+q₂)，平移为 [x,y,0]ᵀ。
逆解（仅指定末端位置）：
```text
c₂ = (x²+y²−l₁²−l₂²)/(2l₁l₂)
s₂ = ±√(1−c₂²)
q₂ = atan2(s₂,c₂)
q₁ = atan2(y,x) − atan2(l₂s₂,l₁+l₂c₂)
```
理想、无关节限位时位置可达条件：|l₁−l₂| ≤ √(x²+y²) ≤ l₁+l₂。通常有肘上、肘下两支；边界上可能合并。若等长两杆末端在原点，折叠构形存在特殊退化，不能机械套 atan2(0,0)。
2 个自由度不能一般地独立满足平面位置 x、y 和姿态 φ 三个约束。若额外指定 φ，必须检验与解的兼容性。
### 4.7 逆运动学的工程筛选
解析法：几何、代数分离变量等；数值法：迭代求解位姿误差。解可能不存在、唯一、多个或在冗余情况下形成连续集合。
筛选顺序：目标可达 → 关节限位 → 碰撞检查 → 与上一时刻解连续 → 远离奇异性 → 满足速度/加速度及其他任务约束。
【拓展】位置任务可用 q_(k+1)=q_k+J_p⁺(p_des−p(q_k)) 迭代，并加入步长、限位和终止判据。全位姿误差不能直接把旋转矩阵九个元素随意当作三个角误差。数值法未收敛不等于目标必定不可达，也可能是初值或算法设置不佳。[S2：IKinSpace]

## 五、第 4 章：雅可比矩阵
【课件主线】第 4 章第 2—17 页；静力映射为课件习题相关补充。
### 5.1 定义、维数与物理意义
若 p=f(q)，则位置雅可比 J_p=∂p/∂q，满足 dp=J_p dq、ṗ=J_p q̇。有限小变化时使用 Δp≈J_p(q)Δq，不宜对大位移直接线性外推。
完整几何雅可比：V=[v;ω]=J(q)q̇，n 个单自由度关节对应 6×n 矩阵；仅位置则是 3×n；平面 2R 仅 (x,y) 任务则是 2×2。
行：某个任务速度分量受各关节速度影响的关系。列：仅该关节以单位速度运动时，对末端速度的贡献。元素 J_ij：局部传动/敏感系数。不同列可能对应角度与长度，不统一单位不能仅凭数值大小比较“谁更重要”。
### 5.2 几何法构造雅可比【拓展】
所有向量统一表达在基坐标系，o_n 为末端点，o_(i−1) 为关节轴上一点，z_(i−1) 为该轴单位向量。
```text
转动关节：J_i = [z_(i−1) × (o_n−o_(i−1)); z_(i−1)]
移动关节：J_i = [z_(i−1); 0]
```
这是“末端参考点线速度＋角速度”形式的几何雅可比。它不能与参考点、排序不同的空间螺旋雅可比直接混用。欧拉角变化率也通常不等于角速度 ω。
### 5.3 平面 2R 的雅可比与奇异性
```text
J_p = [−l₁sinq₁−l₂sin(q₁+q₂)   −l₂sin(q₁+q₂)
        l₁cosq₁+l₂cos(q₁+q₂)    l₂cos(q₁+q₂)]
det(J_p) = l₁l₂ sinq₂
```
当 q₂=0 或 π（模 2π）时，针对二维位置任务的雅可比降秩，瞬时可实现速度方向减少。机械关节没有消失，丢失的是任务空间某些瞬时运动能力。
例如 l₁=l₂=1、q₁=0、q₂=0 时 J_p=[0,0;2,1]，只能产生 y 方向瞬时速度，不能产生非零 x 方向瞬时速度。
非方阵不能使用行列式判奇异，应看秩、奇异值或任务所需秩。接近奇异位形时，某些给定末端速度需要非常大的关节速度。
### 5.4 逆速度求解与处理方法【拓展】
方阵可逆时 q̇=J⁻¹V。冗余或非方阵可使用伪逆 q̇=J⁺V；不可实现的任务速度只能得到某种最小二乘意义的近似。
阻尼最小二乘：q̇=Jᵀ(JJᵀ+λ²I)⁻¹V，λ>0。阻尼可缓解奇异附近速度放大，但会牺牲跟踪精度，不能让本来不可达的速度变得完全可达。
工程措施：改变路径/姿态、降低速度、设置关节速度限幅、监测最小奇异值、选择连续逆解分支。姿态与位置同时优化时还需合理量纲缩放。
### 5.5 静力映射与虚功
采用同一点、同一坐标系和配对排序：V=[v;ω]，F=[f;m]。由功率 τᵀq̇=FᵀV 得到 τ=JᵀF。
若 F 定义为机器人对环境施加的力，则 JᵀF 是相应输出负载需求；若 F_ext 定义为环境作用于机器人，则静态平衡中驱动力通常需抵消 JᵀF_ext，并考虑重力。符号必须跟随受力方向定义。
不能把 τ=JᵀF 错写成 τ=J⁻¹F。方阵可逆时反求 F=J⁻ᵀτ；这也不代表动态运动时可以忽略惯性、重力、摩擦等。

## 六、第 5 章：轨迹规划
【课件主线】第 5 章第 3—27 页；原始计算练习第 15、22、29 页。
### 6.1 路径与轨迹、点位与连续路径
路径只描述几何形状；轨迹加入时间信息，描述 q(t)、q̇(t)、q̈(t) 或末端位姿随时间变化。
点到点运动侧重起终点，但中间路径仍要安全无碰撞。路径跟踪还要求途中位置、姿态、速度等满足工艺要求，例如焊接。实际系统有模型误差和扰动，不能保证实际路径在所有时刻与理想路径数学意义上完全一致。
### 6.2 关节空间与笛卡尔空间
|比较|关节空间规划|笛卡尔空间规划|
|直接规划量|关节角/位移|末端位置与姿态|
|优势|实现较直接，易检查关节限位与同步|路径形状直观，适合直线、圆弧工艺|
|主要风险|末端路径一般不是直线|途中不可达、奇异、逆解分支跳变|
|检查内容|末端碰撞、路径是否满足工艺|关节位置、速度、加速度及力矩限制|

共同流程：任务与边界条件 → 几何路径 → 时间参数化 → 运动学转换 → 全程约束检查 → 仿真 → 安全条件下执行。端点可达不等于中间点可达。
### 6.3 三次多项式：四个边界条件
设时间区间 t∈[0,T]，q(0)=q₀、q(T)=q_f、q̇(0)=v₀、q̇(T)=v_f，Δq=q_f−q₀。
```text
q(t)=a₀+a₁t+a₂t²+a₃t³
a₀=q₀；a₁=v₀
a₂=3Δq/T²−(2v₀+v_f)/T
a₃=−2Δq/T³+(v₀+v_f)/T²
q̇=a₁+2a₂t+3a₃t²；q̈=2a₂+6a₃t
```
首尾静止时，令 u=t/T：q=q₀+Δq(3u²−2u³)。峰值 |q̇|_max=1.5|Δq|/T；区间内最大加速度幅值为 6|Δq|/T²。
因此只考虑速度上限 v_lim 和加速度上限 a_lim 时，T 至少满足 max(1.5|Δq|/v_lim, √(6|Δq|/a_lim))。多关节统一总时长还应取各关节要求的最大值，并另行检查力矩和碰撞。
三次插值保证给定位置与速度边界，但首尾加速度一般不为零。与静止段拼接时加速度可能跳变。
### 6.4 分段三次与五次多项式
过中间点的分段三次：各段使用局部时间，令相邻段端点位置相同，并设置一致的接点速度。若还要求加速度连续，需要额外约束或求解样条问题，不能认为任何分段三次天然二阶连续。
五次插值有 6 个系数，可给定两端位置、速度、加速度。两端速度和加速度均为零时：[S2：QuinticTimeScaling]
```text
q=q₀+Δq(10u³−15u⁴+6u⁵)
q̇=(Δq/T)(30u²−60u³+30u⁴)
q̈=(Δq/T²)(60u−180u²+120u³)
```
五次多项式与静止段拼接时可保证加速度连续，但 jerk（加加速度 q⃛）不一定连续。真正的 jerk 限制需明确设计，不是阶次越高就自动更好。
### 6.5 抛物线过渡的线性插值（LSPB）
先恒加速、再匀速、最后恒减速，形成梯形速度曲线。以下假设 Δq>0、首尾速度为零、两端过渡时间都为 t_b，匀速段速度为 v：
```text
Δq = v(T−t_b)；t_b=T−Δq/v；a=v/t_b
0<t_b≤T/2，即 Δq/T<v≤2Δq/T
q(t)=q₀+0.5at²                       0≤t≤t_b
q(t)=q₀+v(t−t_b/2)                   t_b≤t≤T−t_b
q(t)=q_f−0.5a(T−t)²                  T−t_b≤t≤T
```
t_b=T/2 时匀速段消失，成为三角速度曲线。LSPB 的位置和速度连续，但加速度在切换时跳变。
原课件例：30°→70°，T=5 s，v=10°/s。Δq=40°，t_b=1 s，a=10°/s²，匀速段为 1—4 s，速度曲线面积为 5+30+5=40°。
### 6.6 笛卡尔直线与姿态插值
位置直线可写成 p(t)=p₀+s(t)(p_f−p₀)，s 从 0 到 1，选择三次或五次时间缩放安排速度。
逐点求逆解时应保持分支连续并检查整个机械臂，而不只是 TCP 是否碰撞。【拓展】姿态可用旋转插值或单位四元数球面插值；不能直接对 R 的各元素做线性插值后就当成合法旋转矩阵。欧拉角还存在周期、顺序与表示奇异性问题。

## 七、拓展：动力学、控制与工程实践
本节超出五章正文的系统讲授范围，但对应第 3 章第 90 页的动力学简答题。建议在正逆运动学和雅可比熟练后学习。
### 7.1 机器人动力学的基本形式
```text
M(q)q̈ + C(q,q̇)q̇ + g(q) + τ_f = τ + JᵀF_ext
```
M：惯性矩阵，常规独立广义坐标模型中对称正定；Cq̇：科里奥利与离心效应；g：重力项；τ_f：摩擦项；τ：驱动广义力；F_ext：环境作用于末端的外力/力矩。[S2：InverseDynamics；本文采用“环境作用于机器人”的外力方向]
正动力学：已知状态与驱动力，求加速度。逆动力学：已知期望位置、速度、加速度与负载，求驱动力。常用建模方法是拉格朗日法与牛顿—欧拉法。
耦合：一个关节的加速或转动会改变其他关节所需的力矩，表现为惯性矩阵非对角项及速度相关项。即使每轴独立控制，也不能推断机械动力学相互独立。
### 7.2 平面 2R 的简化动力学模型
设机械臂在竖直平面内运动，q₁ 从水平 x 轴起算，q₂ 为相对角，重力沿 −y。连杆质量 m₁、m₂，质心到各自近端的距离 r₁、r₂，质心转动惯量 I₁、I₂。忽略摩擦和外力，重力加速度幅值为 g₀。
```text
M₁₁=I₁+I₂+m₁r₁²+m₂(l₁²+r₂²+2l₁r₂cosq₂)
M₁₂=M₂₁=I₂+m₂(r₂²+l₁r₂cosq₂)
M₂₂=I₂+m₂r₂²
h=m₂l₁r₂sinq₂
c₁=−h(2q̇₁q̇₂+q̇₂²)；c₂=hq̇₁²
g₁=(m₁r₁+m₂l₁)g₀cosq₁+m₂r₂g₀cos(q₁+q₂)
g₂=m₂r₂g₀cos(q₁+q₂)
τ=Mq̈+[c₁,c₂]ᵀ+[g₁,g₂]ᵀ
```
不用死记长式，优先识别“惯性＋速度相关＋重力”三类。若臂在水平面运动且轴线竖直，驱动轴上的重力项模型不同，不能照搬。
### 7.3 闭环控制、PD 与模型补偿
误差 e=q_d−q。最基本的 PD 形式 τ=K_p e+K_d ė；比例项纠正位置误差，微分项改善阻尼。增加重力补偿可减少静态负载误差，但参数不准、饱和、摩擦会影响效果。
模型补偿的计算力矩思路：τ=M(q)[q̈_d+K_d ė+K_p e]+Cq̇+g。在理想模型、无外扰、无饱和条件下，可将误差动态设计得较简单；实际必须考虑稳定性、噪声与控制频率。[S2：ComputedTorque]
阻抗控制的核心是规定力与位移/速度之间的期望动态关系，适合接触任务；不是一味把位置增益调得很高。任何算法都不能替代硬件安全链与风险评估。
### 7.4 传感器、标定与误差来源
编码器测关节位置；相机识别工件/环境；力矩传感器支持接触检测；IMU 常用于移动或姿态估计。测量精度、采样周期、延迟与噪声都会影响控制效果。
TCP 标定确定工具坐标系相对法兰的变换；基座/工件标定确定工作参考系；手眼标定确定相机与机器人之间的关系。重复性良好但整体偏移时，应先检查坐标标定、零位与工具参数，再盲目提高控制增益。
### 7.5 进一步学习路线与安全边界
推荐后续主题：螺旋理论与指数积建模、轨迹优化与碰撞检测、状态估计、视觉伺服、力控制、移动机器人定位与导航、机器人软件通信与仿真。
阅读《Modern Robotics》时注意其螺旋速度通常按 [ω;v] 排列，且空间螺旋的线速度分量不总等于本文所说 TCP 点的线速度，不能直接复制雅可比进入本文公式。
实验顺序：纯仿真 → 检查单位和关节限位 → 低速无载 → 安全防护下分阶段加载。急停、限位、防护、负载保持与碰撞风险必须按设备手册和适用安全要求检查。本讲义不是可直接部署的工业控制或安全认证方案。

### 11.1 三次轨迹绘图（对应第 46、59 题）
本程序仅用于离线计算和绘图，不含真实机器人接口。角度使用 degree，速度为 degree/s；若输入控制器要求 rad，应先转换。程序附带端点自检；本讲义制作时已用 Python 独立复算数值，但未在 MATLAB 环境执行此脚本。
```matlab
clear; clc; close all;
q0 = -5; qf = 80; T = 4;
t = linspace(0,T,401);
dq = qf-q0;
a0 = q0; a1 = 0;
a2 = 3*dq/T^2; a3 = -2*dq/T^3;
q   = a0 + a1*t + a2*t.^2 + a3*t.^3;
qd  = a1 + 2*a2*t + 3*a3*t.^2;
qdd = 2*a2 + 6*a3*t;
assert(abs(q(1)-q0)<1e-9 && abs(q(end)-qf)<1e-9);
assert(abs(qd(1))<1e-9 && abs(qd(end))<1e-9);
subplot(3,1,1); plot(t,q,'LineWidth',1.5); grid on;
ylabel('q (deg)'); title('Cubic joint trajectory');
subplot(3,1,2); plot(t,qd,'LineWidth',1.5); grid on;
ylabel('dq/dt (deg/s)');
subplot(3,1,3); plot(t,qdd,'LineWidth',1.5); grid on;
ylabel('d2q/dt2 (deg/s^2)'); xlabel('t (s)');
fprintf('Peak speed: %.6f deg/s\n',max(abs(qd)));
```
### 11.2 建议的自检练习
改变 T 为 8 s，保持角度端点不变：峰值速度应减半，峰值加速度应变成原来的四分之一。再把三次时间缩放换成五次，比较端点加速度与峰值速度；不要只凭曲线“看起来平滑”就断言满足所有约束。
用 2R 模型做数值差分雅可比检查：每次将某个关节增加很小的弧度 ε，计算 [p(q+εe_i)−p(q)]/ε，与解析 J 的第 i 列比较。ε 太大导致截断误差，太小会放大浮点舍入影响。
